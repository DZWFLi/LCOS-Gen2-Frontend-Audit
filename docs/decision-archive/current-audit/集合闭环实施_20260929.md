# T6 集合闭环实施记录 · 2026-09-29

已把 canonical Collection 的成员写入串到主画布。Collection 身份/成员属于 Core 真值；Huabu 节点只投影该身份，`parentId`、旧 Scope 和 View/空间投影都没有被当作成员关系。

## 已落地

- Core metadata schema 57 新增 `collections` 与 `collection_memberships`。迁移不把旧 `Scope(kind=collection)` 自动复制成第二个集合实体。成员唯一约束、集合与成员同项目约束、实体存在校验在持久化事务里执行；嵌套集合拒绝环并限制两层深度。
- 新增 Collection 查询/创建/成员增删路由与 typed client。可添加同项目 artifact、note、canonical collection、普通 scope、workspace、connected conversation 和 run。没有持久 canonical 身份的 system skill，以及 View、画布节点等投影引用会明确拒绝。
- 创建与成员变化写入 ChangeSet；新增/移除均有真实回执，重复新增返回 `already-member`，重复删除返回 `not-member`。成员增删支持安全 undo/redo；集合身份仍有成员时不能撤销创建。
- 主画布 reconciliation 只投影 canonical Collection。Drop 至真实 Collection 节点会提交成员写入；投影 descriptor 读取真实成员，Collection 面板显示成员、可展开/收起更多成员并逐项移除。成功后刷新投影，失败显示移除失败状态，不伪报成功。
- Context Atlas 顶栏的既有集合入口新增“新建集合”表单。创建后刷新当前 ProjectionBinding，只在 `waitForProjectedEntity` 找到同画布真实投影时发出定位；Core 已创建但当前无画布/投影超时会单独说明，不伪报定位成功。
- Collection 卡片可“展开到画布”：先读取当前 Canvas 的 canonical 成员投影，再调用 Huabu 原生 `selectNodes` + `frameSelectedNodes`，以 `lcosCollectionId` 标记纯空间 Frame。成员已有其他 Frame 父级时禁用，避免覆盖现有布局。Frame 中同时呈现 Collection 投影和真实成员；“收起空间”调用 Huabu `unframe` 恢复子节点原空间位置。`parentId` / `lcosCollectionId` 只描述空间布局，不读写 canonical membership。
- 空集合不显示模拟预览纸片；缺少可读标题的成员仍可按真实类型与 ID 识别。

## 验证

- Local Core 定向测试：5 个文件、51 项通过，覆盖 schema 迁移、成员读写、重复回执、撤销/恢复、跨项目/不存在实体拒绝与环检测。
- Huabu 定向测试：3 个文件、26 项通过（Context Atlas、Collection body、Drop）；Huabu 与 web-gen2 TypeScript typecheck 通过。Local Core 使用临时路径映射配置检查本地源类型通过；临时配置已删除。
- 曾运行 Local Core 全套测试：15 个文件失败、134 个文件通过（18 项失败、789 项通过）。其中 4 项是 metadata schema 56→57 带来的旧版本断言，均已修正；其余失败涉及已有 RuntimeBinding/Runtime persistence、Agentlet、search/chunking、sqlite-vec 运行时与旧版 schema 50 断言。按要求未重跑全仓；本批范围内 Core 5 文件 51 项、Huabu 3 文件 26 项定向检查均通过。
