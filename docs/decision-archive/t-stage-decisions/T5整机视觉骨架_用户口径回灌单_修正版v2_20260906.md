## 二、需要回灌的 6 条（修正后口径）

### 🔴 1. Glyth：造型已拍板，别再当"开放课题"
- **用户现状**：早已拍板**直接采用 grok-icon-study 复刻渲染器**（23 种规则几何、每形带动画面参数表；36 状态×4 组、每状态配眼睛播放列表+停留时长+眨眼节奏；15 根弹簧变换；25 组眼型 morph；12 色双档渐变 + 13 种 overlay；pose 系统）。
- **署名义务（强制）**：界面需展示「Grok Bot 造型参考 · blessonism/grok-icon-study · xAI Grok」；本仓库无 LICENSE，数据源自 Grok Bot.app——商业化前必须复审/换数据。
- **T5 现状**：写的是"Glyth 是最重要视觉课题之一、最终形态仍开放"。
- **回灌动作**：改为"采用已拍板方案"，T5 只做微调（符合"最多调色号/大小/时长/强度"原则），不再重新设计；署名写入视觉红线。

### 🟡 2. Collection：照"轻文件夹卡"做，沿 Gen1 / Spatial
- **用户口径**：Collection 沿用 Gen1 的做法，Gen1 的 Collection 是直接学 Spatial 的。
- **Spatial 事实**（源码/录屏已拆）：文件夹卡 = **成员缩略预览 + 标题 + 星标角标**的轻卡；item 归入文件夹用 parentFolder；容器可原地展开/折叠，**不是点进去一张新画布**。
- **T5 现状**：写的是"基于 Huabu Frame mechanics、边界极轻、Expanded/Collapsed"——方向对。
- **回灌动作**：补一句出处——**视觉直接对标 Spatial 文件夹轻卡（成员缩略+标题+星标）与 Gen1 沿承**，避免 T5 把它设计成复杂框或新的三层容器。

### 🟡 3. 容器三态（门户⇄装配⇄工作台）：归属 = Context/Workflow/Portal 类"场所组件"，与 Collection 无关
- **用户口径**：冻结的上下文组件、工作流组件需要"能放大常驻、能展开装配编辑、又像门户、又能展现内容物"——即一个容器三态切换。MD6 §9.6.1 已裁决。
- **T5 现状**：对 Collection 写了 Expanded/Collapsed 两态；Professional Window 是另一套窗口系统。
- **回灌动作**：明确三态是**场所组件**（Context / Workflow / Portal）的形态文法，不是 Collection；T5 需在 Context/Workflow 章节给出"同一容器三可切"的视觉处理（内容物缩放显示贯穿三态）。

### 🟡 4. 外显线：按用户原话口径——"讨厌线条外显、贴近才聚、离开散开"
- **用户原话**："我也讨厌线条外显…（hero-constellation）贴近才聚、离开散开"。指的是**别靠一堆连线表达关系**，希望用距离/聚散这类自然方式。
- **表述边界**：不是"绝对禁止一切线条"；跨远域/跨现场时的连线仍可兜底。
- **T5 现状**：Colony 写了"有机、软的边界、成员共同形成的气场"——方向对。
- **回灌动作**：把"关系优先用距离与聚散表达，不依赖外显连线；轮廓平时不显形、选中/编辑才显现"写入 Colony 视觉红线；避免写成禁线教条。

### 🟡 5. 微元素：积极采用现成的点阵/矩阵/扫描/信号类，有功能归因
- **用户口径**：动态不是越少越好；点阵、矩阵、扫描、pulse、signal、halo 这类微元素可大量采用（现有库直接拿），但必须每个都有功能归因。
- **T5 现状**：写了"动效有功能归因"，但对"大量用现成微元素、不重新发明"未点名。
- **回灌动作**：在微系统章节点名 donor（Morphicons / Amicro / toolcase-game-components / orbit-css / React Bits 等，按已定审美库存表），约定"最多调色号/大小/时长/强度"。

### 🟡 6. donor 呈现参考（Spatial / TapNow / Lovart 的成熟呈现直接高保真借）
- **用户口径**：TapNow / Lovart / Spatial 它们"最好的呈现方式就直接拿来用"；donor 可以换，canonical owner 不换。
- **可用参考**（均已拆出、可喂给 T5）：
  - Spatial：内容卡呈现规律（白底内容卡 vs 高饱和强调卡的视觉分层、留白与排布、聚焦打开、编辑态菜单）——为 **donor 参考输入**，非用户逐字口径；
  - Lovart：Assembly Masonry / Source Bay 层级（T5 已点名，对）；
  - TapNow / LibTV：选型参考。
- **回灌动作**：把上述 donor 证据目录挂给 T5 用，明确"视觉骨架阶段先锁 silhouette/层级/用哪个 donor，不锁像素/毫秒/色号"。
