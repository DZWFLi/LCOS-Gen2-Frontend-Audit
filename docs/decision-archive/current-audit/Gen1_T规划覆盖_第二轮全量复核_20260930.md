# LCOS Gen1 × T1–T7 × Gen2 第二轮全量复核

日期：2026-09-30  
源码分支：`codex/gui-figma-recovery-20260926`

## 结论

目前不能说 Gen2 已经把 Gen1 与 T1–T7 全部做对。第二轮穿透检查确认：部分能力已经有真实 producer、binding、renderer、action 和 receipt；部分只有组件或测试；另有几处身份串线已经修复。判断标准统一为：

`真实数据生产者 → 稳定身份 → 画布/窗口绑定 → 可见形态 → 用户动作 → 权威回执 → 重载或回程`

缺其中一段，都不能叫完整实现。

## 已确认错误并修复

### 1. Context Atlas 身份串线

- 错误：把 `scene`、普通 `collection` 和 `context` 一起作为 Context Atlas 的大型块。
- 原裁决：Context Atlas 的每个主体只对应一个 Context collection；Scene / Workspace 是目的地，不是 Atlas 主体。
- 修复：Context Atlas 只接受 `kind=context` 且 `entityRef.type=context`；Main 集合总览只接受 canonical Collection。
- 结果：不再用施工现场、Workflow 现场凑“集合数量”。

### 2. Collection Drop 失败回执被当成成功

- 错误：只要收到集合成员回执，就可能进入成功反馈。
- 修复：必须同时匹配目标 collectionId、memberRef，并且状态为 `applied` 或 `already-member`；`not-member`、`removed`、身份错配全部失败。

### 3. 历史材料打开了最新版本

- 错误：画布呈现某个历史 ArtifactView 时，双击或 Arc「打开」仍把 Reader 指向 artifact 当前最新 revision。
- 修复：投影事实新增 `presentedRevisionId`；Reader 优先打开当前呈现的 revision，只有普通当前视图才回退到 `currentRevisionId`。

### 4. Main Collection 与 Context / Workflow 现场共用外观和入口

- 错误：左下入口使用通用 Layers 图标，Atlas 内同时出现 Collection、Context、Workflow 现场，导致产品概念被糊成“文件夹大厅”。
- 修复：Main 入口和卡面只表达 canonical Collection；Context / Workflow 通过各自 Surface、Atlas、手牌和现场导航进入。

### 5. 节点右键产生第二套菜单

- 错误：右键进入一套与选中态不同的通用菜单。
- 修复：右键先选中对象，再复用同一 Action Arc；次级动作留在 Arc More / inspector。

## 仍未证明正确的关键缺口

### P0

1. **Run / Result 是否真的进入主画布。** Registry 与 renderer 中存在 run、working、decision、context-reference、prompt-frame 等物种，但 ReconciliationRunner 当前主要生产 Artifact、Workflow Scope、Collection、Conversation。必须逐个证明 producer；死 renderer 不能计作功能。
2. **Railway 完整用户链。** 当前 0 目的地时隐藏是合理状态，但“从哪里加入、如何变长、如何稳定回读”还没有整机证据。
3. **六类 Drop Receiver 的统一手感。** 路由和回执不等于用户看得懂；仍需真实高亮、吸附、拒绝、取消、成功、失败和回滚录证。
4. **Context / Workflow 根现场。** Atlas 与手牌局部语义已纠偏，根视图仍需要严格按 T5 专项裁决和 HTML 原型核对关系、证据、时间、阶段、执行与结果。
5. **Glyth 状态机与 provider。** 画布本体应明确表达 idle / thinking / running / waiting-input / success / failure / recovery，而不是只在深窗口里列状态。
6. **Portal 生命周期。** 既有目的地预览/打开不等于完整投递；创建、取消、目标丢失、失败回执和返回来源仍需同一 owner。

### P1

1. Color Pin 顶部灵动岛逻辑基本正确，但成员预览仍需物种、缩略与高饱和轮廓。
2. 浮游标有定位与 arrival 路径，最终 donor 形态与边缘色彩弥散未完全收定。
3. 连线默认隐藏已恢复；选中/关系模式的线、端点、标签和退场仍需 TapNow 近场语言。
4. Assembly 功能 owner 在，但媒体占比、瀑布流、缩放和不同物种面型仍偏后台列表。
5. 多选 toolbar 有 caller，真实框选、组拖、复制、删除、撤销与 Arc 焦点冲突尚缺整机录证。
6. 窄屏、长文本、超多节点、浮层碰撞、滚动和窗口恢复仍需系统性验证。
