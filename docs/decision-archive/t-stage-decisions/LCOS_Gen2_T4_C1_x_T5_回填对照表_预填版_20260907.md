## 2. 可立即吸收的 T5 输入

### 2.1 全局视觉原则

回填状态：`ABSORBED`

- content-first，内容先于 chrome；
- species-specific morphology，不使用统一 generic card；
- selection affordance 为轻量 screen-space overlay，不改变内容 geometry；
- deep view 保持同一 canonical entity identity；
- local formatting/tool overlay 使用 Portal，不进入 canvas layout；
-异构对象允许不同尺寸，空白承担空间操作与信息层级；
- full → compact/minimal → identity/far 必须连续，不闪跳；
- reduced-motion 必须有明确 fallback；
- stale/missing/error 不得吞掉。

### 2.2 Preview / Work View promotion

回填状态：`ABSORBED_WITH_SCOPE_CORRECTION`

回填到 C1：

```text

→ transient preview（同一 targetRef）
→ user interaction promotes
→ Professional Window instance
→ close/focus-back resolves current spatial anchor
```

校正：T5 Phase 1 只证明节点/Preview 语义，Window 的多实例、dock/split/float、session restore 仍由 T4 C1 和后续 T5 Phase 4 定义。

### 2.3 LOD 单一 owner

回填状态：`ABSORBED`

- Huabu `useNodeLOD/useNodeTakeover` 保持唯一 mechanics owner；
- Gen1 zoom bands 只能作为测试输入，不能再建第二套驱动；
- Professional Window body 不反向驱动画布 Node LOD；
- Window 打开时可降低非焦点视觉权重，但不改 canonical selection/geometry。

### 2.5 Spatial motion证据

回填状态：`ABSORBED_AS_CALIBRATION_ONLY`

可采用：

- focus/presented 是同一对象连续变化；
- 邻居降权、让位、settle；
- Collection collapsed 暴露成员形态；
- heterogeneous layout；
- deep reading不是统一modal。

不可升级成硬token：

- 背景scale `.96`；
- opacity `.4`；
- displacement `8–16px`；
- spring `0.25/0.8`。

这些仍是 `INFERRED_CALIBRATION/RECIPE`。约250ms打开、约550ms多卡入场只可标 `REPORT_MEASURED`，待浏览器校准。
