## 3. 必须批准的重大变更

依据 AGENTS 变更协议，以下内容在编码前必须由 Dz 批准 Sprint Scope。

### 3.1 单 Project Canvas identity 迁移

变更原因：当前 `surfacePort.ts` 仍要求 Main/Context/Workflow 使用三个不同 canvasId，与“一 Project 一张持续 Project Canvas”冲突。

变更前：

```text
Project
  ├─ main canvasId
  ├─ context canvasId
  └─ workflow canvasId
```

变更后：

```text
Project
  └─ Project Canvas identity
       ├─ Main Surface mode
       ├─ Context Surface mode
       ├─ Workflow Surface mode
       └─ Semantic Viewports / Worksites
```

用户变化：Surface 切换仍是一级入口，但不再暗示换到另一张 Project Canvas。

数据变化：需要旧 canvas persistence key 的兼容读取/迁移；不得丢布局。

风险：相机、selection、history 隔离策略改变；Huabu persistence 键冲突。

回滚：保留 V0 key 只读兼容，在新 session contract feature flag 下切换。

### 3.2 Canonical Workflow identity 与 composition

变更原因：当前 durable workflow actions/edges/operators 由 Presentation state 代持，不符合 D19。

变更前：

```text
scopeId
→ presentation:workflow:<scopeId>
→ workflowActions / edges / operators
```

变更后：

```text
Workflow identity + versioned typed composition
→ references Project entities
→ Workflow Presentation projection
→ optional explicit Worksite
```

数据变化：需要 Presentation/Scope legacy migration；不可复制 Artifact。

风险：对象模型、导入导出、Rail refs、Assembly target 同时受影响。

回滚：旧 Presentation 保留只读，迁移写入可逆且记录来源版本。

### 3.3 Archive canonical lifecycle

变更原因：当前无 archived/restore truth，仅有 availability 与 hard delete。

变更后需要：

```text
active → archived → restored
```

Archive 保持可搜索、可检查、可恢复；默认从常规 Surface/Assembly候选中排除。不能用 UI hide 替代。

### 3.4 Project Session / Professional Window durable state

变更原因：当前没有 project-scoped window/session owner。

需要区分：

- canonical Project truth；
- durable Presentation；
- durable Project Session；
- transient UI state；
- screen-space derived occupiedRects。

## 22. 回滚总策略

1. 每 Gate 独立 branch/commit须另获授权；
2. schema migration先备份并验证旧库副本；
3. 新 contract使用schemaVersion；
4. legacy reader保留，new writer feature flag启用；
5. 不覆盖旧 Presentation/canvas/session 数据；
6. mutation用ChangeSet或transaction；
7. UI可切回旧adapter，但不得继续写已废弃truth；
8. rollback采用可审查revert，不重写历史；
9. migration失败停止启动写入并提供恢复路径；
10. 所有回滚在handoff报告记录真实结果。
