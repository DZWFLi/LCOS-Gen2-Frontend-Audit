# DZ Dream Signal Motion v4 · 整合与验收

## 交付对象

本轮交付是完整主站，不是独立排版研究页。

在 `CandySignal_v3` 的 Apple / Duo / Ice Works / Archive / Composer / Callback 工作流程上，整合已经认可的 `Editorial Study 01` 视觉关系；使用用户提供的 v03 外壳，内腔与小苹果叙事保留当前实现。原交付 HTML、研究稿和用户 ZIP 没有覆盖。

主文件：`DZ_DreamSignal_Motion_v4.html`。运行脚本、样式、26 个本地素材和许可内嵌。浏览器须启用 JavaScript 和 WebGL2。

## 本轮真正增加的平面动效

| 位置 | 发生什么 | 触发与收束 |
|---|---|---|
| 开场大字 | 中文两行分别从遮罩下显影；背景 DREAM、实色色带分段入场 | 初次进入 / 重置播放。打开苹果时印刷图层让出主体 |
| 三个入口 | 大英文分成三个水平切片错位归拢；中文信息逐行显影；色带和编号依次展开 | 切换当前章节触发，结束后保持清晰，不持续乱码 |
| 入口图案 | SDF 图集内的印刷线段轻扫；背景印刷层按水平条带显影；条形图案响应悬停 | 沿用现有 hover / active 状态；离开后回到收束状态 |
| 透视墙 | 卡片增加裁切大编号；分段色条进入当前卡后展开，悬停时短促收合再展开 | 仍跟随原卡片移动，不另建轮播或额外透视场景 |
| 案例详情 | 九点矩阵读取，三段状态条；标题、Role / Problem / Move / Output 顺序揭示；证据区纵向裁切展开 | 小窗 → reading → expanding → ready。加载完成后点阵停止，不人为延长全屏 loading |
| 人物 Callback | BEHIND / STILL CURIOUS、大字介绍、色带和半色调随滚动出现；碰撞帧出现 IDEA! 和冲击标记 | 取同一 callback progress。倒滚恢复、终章退出，不另开人物页 |

这些图案不是铺满屏幕的装饰背景。图案、排字和信息的主要关系是：大字负责第一眼信息，几何负责章节辨认，色带负责节奏，细线和编号负责次级细节。正文阅读时收起持续运动。

## 构图与配色

- 背景：继续使用原 `assets/grass-sky.jpg`，不换成白色页面。内容区有适度浅色遮罩以保证文字阅读，仍能看到天空、地平线与草地。
- 大标题：沿用 v02 大字、紧字距、两行短句的关系，重新按主站空间安排尺寸。桌面中文主标题约 105px（1440px 视口）；手机约 45px（390px 视口）。
- 一级入口：Projects 酸黄、About 冷青、Workflow 粉色。颜色集中于章节图形和色带，不大面积覆盖作品封面。
- 入口图形：使用研究稿已经采用的 Coolshapes 轮廓，加入大编号、局部裁切与印刷色块。不是重新制作一组 Three.js 球、盒子或“卫星”。
- 关键文字为原生 DOM，可选择、可读、可访问。背景巨字是低优先级图形，由同一 WebGL 背景合成。
- 窄屏与横屏独立调整字级、标题位置、主入口操作宽度，避免为了塞下内容统一缩成小字。

## 苹果与手

### 只把外壳换回 v03

实际调用的 v03 外部几何、轮廓和材质放在 `src/apple/exterior03/`。没有导入 v03 旧的 Intro 主流程或旧内腔。

v03 本身是深红树脂透射材质，不是简单的“transmission=0”。本轮按原参数承接，主帧循环不再覆盖其颜色、粗糙度与 clearcoat。光照角度仍处于现有主站的空间中，所以与旧独立截图不保证逐像素一致。

保留当前 `field.js` 里的迷雾等高线和印刷内腔。新手、小真实苹果、离手、接管后续原点、最后吃掉的逻辑沿用当前版本。

### 承托对位

手的可见 geometry 从原 -0.14 位移到 -0.27，即继续向左小幅移动；`palm()` 和 `seedTransfer()` 没有改变。小苹果的起始尺寸与新壳体宽度解耦，避免换回 v03 后被顺带放大。窄屏对整个开场外壳作 10% 的适配缩放，防止完整打开时越出视口；后续入口锚点目标不变。

## 没有重做的交互

仍然由原代码负责：左翻开合、滚轮与拖动、惯性与吸附、一次一个完整入口、章节任选、完成后退出选择、有限双翼墙、案例抽取与关闭、最后一个章节才吃苹果、同场连续人物 Callback 与 DZ 收尾。

逐文件对比确认以下模块与本轮开始时的当前主站一致：

`apple/field.js`、`apple/fold.js`、`apple/seed.js`、`apple/real.js`、`apple/cameo.js`、`journey.js`、`ring/engine.js`、`ring/math.js`、`ring/params.js`、`archive/math.js`、`outro/particles.js`、`outro/choreography.js`。

世界时钟只额外传入视觉身份与 hover 状态；新增图形不拥有鼠标或滚轮。SDF shader 仅增加印刷颜色事件，并压低新版图集黑色小字在连接桥上的延伸色，避免连接线像粗黑条穿过版面；没有改距离场、桥的路径、采样位置或吸附算法。

### 视觉修正记录

开发期发现并修正：大英文三个切片使用不同盒子导致接缝、手机长入口动词换行、九点读取被旧 span 规则改成非 grid、碰撞字因绝对定位内容导致容器宽度为零、横屏编号与页头过近、连接桥被新版深色印刷纹理染成粗黑色。

第一次测试的少数“未到最终文字状态”来自固定睡眠时长在软件 GPU 中不稳定；测试改为等待实际 material / DOM / animation 完成状态，再判断最终可读性，而不是跳过断言。初次结果保留于 `verification/first-pass/`，最终结果以 `verification/final/` 为准。

## 已知边界

1. 不是原生 Next.js / GSAP 上游网站重新部署，而是当前已认可离线兼容主站的视觉整合。
2. 真实手机硬件、Safari、Edge 与原生 file:// 双击路径尚未实测。浏览器内的完整 HTML 行为已验证，不扩大声称。
3. 使用系统字体栈，不随包分发字体文件。不同系统的英文字体形状和文字宽度可能不同。
4. 12 个项目、3 个自我介绍项、6 个方法项沿用原 `content.json`；样例封面和模板证据仍待用户替换。本轮未编造新的商业成果。
5. 用户人像沿用原像素裁切，没有生成陌生人；源图本身的遮挡或原始分辨率限制仍存在。
6. 没有部署、发布或推送到外部账号。
