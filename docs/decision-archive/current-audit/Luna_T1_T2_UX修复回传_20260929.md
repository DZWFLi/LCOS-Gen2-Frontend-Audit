## 改了什么

Collection Main 节点现在按相机密度显示同一磨砂文件夹的三档读法：近景保留封面槽、标题与组织行；中景压去次级行和第二张封面，保留标题；远景去掉屏幕上只剩几像素的文字，只留文件夹轮廓与固定屏幕尺寸的身份图标。Workflow 书册沿同一 mark 规则处理，进入现场按钮在远景维持可点尺寸。

同时，Collection 节点不再把 Huabu 节点 `data.src` / `presentationMediaSrc` 当作集合成员封面传给 CollectionFace。当前没有 canonical member list/read，图片来源不足以证明它是集合成员；保持空预览比让任意图片冒充成员实在。

**前后差异：** 之前 mark 档仍将标题设为 20 world px，随相机缩小后不可读；小图标也随节点缩到几像素。现在文件夹外形仍跟空间缩放，图标单独按 zoom 与 face-fit 反向补偿，在 mark 时维持屏幕尺寸；summary 保留标题，near 保留细节。没有写成员数量或伪造成员缩略图。
