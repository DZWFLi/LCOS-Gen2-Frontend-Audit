# Canvas 连线显示开关（2026-09-29）

## 结论
LCOS 画布现在默认收起普通关系线，可从现有空间导航器按需显示/隐藏。这个偏好只影响 ReactFlow 的显示投影：没有删改关系数据，连接手柄仍在，Huabu 原生画布不受影响。

## 依据与采用
- 原始施工依据：`_cabin/01_正本/GEN2_新前端重新总装正本_20260913/references/original_route_cards/T2/LCOS_Gen2_T2_C1_Consolidated_ExactFile_SourceConstructionPlan_20260906.md` §G7。复用既有 Spatial Navigator、ReactFlow 和 Huabu camera/pref owner，不新建 Canvas 状态系统。
- Figma 采用边界：`_cabin/06_Figma/LCOS_GEN2_Figma设计合同轻包_仅MD_20260914__unzipped/02_多阶段设计采用边界.md`，空间导航器沿用既有入口。连线开关是根据现有控制区加入的产品推断，并非声称 Figma 明确画了该按钮。
- TapNow 拆包 CSS：`_cabin/02_施工卡/施工前最后一轮校准/tapnow_拆包_20260904__unzipped/tapnow_raw/assets/vendor-pkg-canvas-CHU-0IGm.css`。只核对到 ReactFlow 默认连线约 1px；没有复用 TapNow 专属关系语义或代码。当前 LCOS 开启时以轻线宽和较低不透明度减少杂乱。

- `huabu/apps/web/src/store/canvasStore.ts`：用既有本地 Canvas 偏好 owner 保存 `huabu.edgesVisible`；首次默认 `false`。
- `huabu/apps/web/src/components/Panels/Canvas/Canvas.tsx`：仅 LCOS chrome 下依据偏好投影 `displayEdges` 或空数组。真实 `displayEdges`/Core relation 未更改，Huabu native 分支仍照旧。
- `huabu/apps/web/src/lcos-seam/types.ts`、`huabu/apps/web/src/lcos/navigation/LcosSpatialNavigator.tsx`、`huabu/apps/web/src/lcos/ui/families/LcosSpatialNavigatorView.tsx`：把状态及切换动作接到原控件；按钮有动态名称、tooltip 与 `aria-pressed`。

- `huabu/apps/web/src/index.css`：只细化 LCOS 连线视图中的非选中关系路径；不隐藏工作流/时间轨引导，不移除 interaction path 或 handles。
