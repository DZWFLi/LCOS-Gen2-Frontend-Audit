# Main 集合总览：身份错接修复

结论：Main 的「项目集合总览」现在只展示真实 canonical Collection；点击只定位当前主画布上同一 Collection 投影，不再把现场/Workspace 当集合入口，也不跳到别的现场。

依据：Figma 总采用说明 [atlas.json](</E:/TRAE项目/LCOS0.1收口/_cabin/06_Figma/LCOS_Figma_全设计包_20260913/unification/specs/atlas.json:61>) 将 Context 定义为 Collection 强表征、Main 为同身份压缩投影；Main 入口不能借 scope/worksite 类型猜成 Collection。[ContextWorkflow 产品语义裁决](</E:/TRAE项目/LCOS0.1收口/_cabin/06_Figma/LCOS_GEN2_Figma设计合同轻包_仅MD_20260914__unzipped/03_ContextWorkflow产品语义裁决.md:28>) 保留 Context/Workflow 现场独立、共享 canonical identity 的边界。旧 T1 Collection 施工卡要求主画布定位落在现有 Collection projection 上：[原始施工卡](</E:/TRAE项目/LCOS0.1收口/_cabin/01_正本/GEN2_新前端重新总装正本_20260913/references/original_route_cards/T1/LCOS_T1_PhaseC1_Step2A_Collection_VisibleHost_ExactSource_Plan_20260906.md:1>)。

代码改动：

- [contextAtlasSemantics.ts](</E:/TRAE项目/LCOS0.1收口/LCOS_GEN2_GUI_RECOVERY_20260926/huabu/apps/web/src/lcos/surfaces/context/contextAtlasSemantics.ts>) 新增严格筛选：同时要求 `kind === collection`、`entityRef.type === collection` 和非空 canonical id；Context 原筛选语义保持不变。
- [ContextAtlasStage.tsx](</E:/TRAE项目/LCOS0.1收口/LCOS_GEN2_GUI_RECOVERY_20260926/huabu/apps/web/src/lcos/surfaces/context/ContextAtlasStage.tsx>) 增加明确 `main-collections` 展示模式；Main 模式不解析 Workspace targets，不提供现场打开/切换动作，不投影时给出“当前画布尚无可定位的集合投影”，无投影项不显示误导性跳转箭头。真实空集仍显示“还没有集合”。Context 默认模式及它的现场导航逻辑未改。
- [MainCollectionAtlas.tsx](</E:/TRAE项目/LCOS_GEN2_GUI_RECOVERY_20260926/huabu/apps/web/src/lcos/surfaces/main/MainCollectionAtlas.tsx>) 删除 Main 到 worksite 导航路径；仅按精确 Collection entity ref 找当前画布节点并发 `requestLocate`，保持 Atlas 打开直到定位目标真实存在。没有集合节点时不伪造成功。
- [LcosProjectShell.tsx](</E:/TRAE项目/LCOS_GEN2_GUI_RECOVERY_20260926/huabu/apps/web/src/lcos/shell/LcosProjectShell.tsx>) 入口提示改为「项目集合（不含现场导航）」，与独立的工作流手牌区分。

验证：定向 Vitest 3 个文件 12/12 通过，覆盖 Main 只定位 canonical Collection、现场/错误 entity ref 被拒、无投影不关闭总览，以及 Context 原筛选保持不变。命令：`vitest run src/lcos/surfaces/main/MainCollectionAtlas.test.tsx src/lcos/surfaces/context/ContextAtlasStage.test.ts src/lcos/surfaces/context/ContextAtlasStage.request.test.tsx`。未做浏览器验收；本轮按主审指令不操作共享页面。

剩余边界：Atlas 的用户动作是原地定位/聚焦同一个 Collection 节点；节点本身既有「展开集合」空间动作仍由 Collection node owner 提供，Atlas 不复制一份展开状态或 Frame 写入逻辑。浏览器总体验证待主审与前序代理完成后再交接。
